# Tuti Lab Community

An open collaboration space for research, experiments, and development around Tuti — an intelligent assistant for hospitality workflows.

Tuti began with a practical observation: hospitality teams spend significant time answering repetitive questions, collecting information, and keeping operational context organized. This repository is the public meeting point for ideas, sanitized experiments, technical discussions, and contributions. It is separate from Tuti's private operational repositories.

## What we are exploring

- Reliable memory: information that can be stored, related, retrieved, and traced to its source.
- Context-aware assistance: understanding scope and constraints before answering.
- Hospitality workflows: pre-arrival questions, guest communication, and operational handoffs.
- Human–AI collaboration: combining domain knowledge, software engineering, and AI tools.
- Accessible design: interfaces that are understandable and useful for non-technical operators.

## How to participate

1. Read [VISION.md](VISION.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
2. Browse [experiments](experiments/) and [discussion topics](discussions/).
3. Open an Issue for a question or proposal, or a Pull Request for a focused documentation change.
4. Explain the problem, evidence, expected behavior, and limitations.

## Collaboration principles

- Evidence before assumptions.
- Small, reviewable steps instead of large rewrites.
- Preserve working systems and their history.
- Separate verified facts, hypotheses, and proposals.
- No production changes without explicit review and approval.
- Protect guest, customer, personal, and operational information.

## Project status

This is a public collaboration and research space, not the production codebase. Tuti's operational repositories, credentials, private data, and deployment configuration remain private.

The first public research topic is memory reliability: why a system can retrieve relevant records but still return candidates that do not satisfy all the conditions in a question.

Portuguese and English are welcome. Thoughtful criticism and focused contributions are encouraged.
